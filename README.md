# viruses

Virus and malware collection for study and writeups. Indexed in code.db on krisyotam.com.

## Structure

```
asm/            ancient DOS/Win9x ASM source codes (~1000 files, alpha-organized)
worm/           self-replicating worms
exploit/        CVE-specific exploits and PoCs
ransomware/     ransomware samples and builders
trojan/         trojans and RATs
prank/          harmless educational scripts
```

Each entry has a `meta.yaml` with name, description, CVE/year, OS, and tags.

For educational and research purposes only.
